# Чат-бот поддержки учебного портала

Учебный прототип для лабораторной работы 3 по дисциплине «Проектное управление в ИТ». Реализация: Vue 3, TypeScript, Vite. Перенос функциональности из общего командного support_bot.html.

## Запуск

Требуется Node.js, соответствующий engines в package.json. Для встроенных тестов используйте Node.js 24.12 или новее.

```sh
npm install
npm run dev
```

Откройте локальный адрес из терминала. Остановка — Ctrl+C.

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

build проверяет TypeScript и создаёт production-сборку в dist. Сборку нужно отдавать через HTTP-сервер; открытие index.html двойным щелчком не поддерживается.

## Возможности

- US1: приветствие, примеры вопросов, меню и адаптивный интерфейс.
- US2: ответы FAQ про вход, пароль и учебные материалы.
- US3: поиск по ключевым словам с приоритетом восстановления пароля. Распознаются «Как авторизоваться?» и «Где конспекты?».
- US4: ответ на неизвестный вопрос и переход к форме.
- US5: демо-форма с проверкой обязательных полей, пробелов, формата email и ограничений длины. Демо-номер и подтверждение корректного заполнения.

Enter отправляет вопрос; Shift+Enter добавляет строку. Команда «меню» показывает подсказку. Кнопка нового диалога очищает чат. Диалог формы закрывается крестиком, Escape и нажатием на фон.

## Границы прототипа

Это локальный FAQ, без языковой модели и подключения к настоящему учебному порталу. Форма не отправляет письма и не создаёт заявки на сервере. Диалог, счётчик и данные формы хранятся только в памяти текущей страницы; обновление их очищает. Оценки ответов US6 и сохранения истории US7 нет.

Шрифт Golos Text подключается из Google Fonts. Если сеть недоступна, используется системный шрифт; логика приложения не требует интернета.

## Структура

- src/App.vue — корневой RouterView.
- src/pages/SupportPage.vue — страница поддержки и координация компонентов.
- src/pages/SupportPage.scss — компоновка страницы и адаптивные правила.
- src/components/SupportChat.vue — диалог и ответы.
- src/components/SupportSidebar.vue — боковое меню.
- src/components/SupportContact.vue — блок обращения.
- src/components/AppHeader.vue — шапка страницы.
- src/components/ThemeToggle.vue — переключатель темы.
- src/components/TicketDialog.vue — форма, ошибки и подтверждение.
- Иконки импортируются напрямую из @lucide/vue (Lucide).
- src/lib/faq.ts — типы, справочник и поиск.
- src/lib/ticket.ts — нормализация и валидация.
- src/styles/main.scss — только базовые правила.
- src/styles/themes.scss — палитры светлой и тёмной тем.
- src/composables/useTheme.ts — выбор темы и сохранение настройки.
- Стили компонентов и адаптивные правила находятся в scoped SCSS внутри соответствующих .vue-файлов.
- tests/support.test.mjs — 18 автоматических тестов FAQ, формы и выбора темы.

## Для общего отчёта

В разделе Increment нужно заменить описание единственного support_bot.html на Vue-проект; обновить скриншоты и результаты проверок. Пользовательские истории US1–US5 сохраняются. Сам общий отчёт этим переносом не редактировался. Распределение реального вклада и описание событий спринта согласуются командой.

## Темы

Переключатель находится справа в шапке. При первом открытии учитывается системная тема; явный выбор сохраняется в localStorage. Цвета меняются в src/styles/themes.scss; компоненты используют CSS-переменные. Данные обращений и переписки по-прежнему не сохраняются.
