# Проверка Vue-прототипа

Дата проверки: 9 ноября 2026 года.

## Автоматические проверки

- `npm run build` — успешная проверка TypeScript и production-сборка Vite.
- `npm test` — пройдено 18 тестов в `tests/support.test.mjs`, включая выбор темы.

Автоматически проверены новые формулировки, регистр и пробелы, прежние темы FAQ, приоритет восстановления пароля, неизвестный и пустой запросы; обязательные поля формы, пробелы вместо текста, неверные адреса, корректные данные, нормализация и ограничения длины.

## Проверки в браузере

| Сценарий | Наблюдаемый результат |
| --- | --- |
| Ввод «Как авторизоваться?» | Показан ответ о входе на портал |
| Ввод «Где конспекты?» | Показан ответ о материалах курса |
| Отправка пустой формы | Ошибки у трёх полей; фокус на первом некорректном поле |
| Пробелы в имени и описании, неправильный email | Показаны ошибки обязательных полей и формата почты |
| Корректные вымышленные данные | Показано подтверждение DEMO-001; явно указано отсутствие отправки оператору |
| Неизвестный вопрос «Мне нужен оператор» | Резервный ответ и кнопка открытия формы |
| Enter в поле вопроса | Вопрос отправлен, поле очищено |
| Новый диалог | История очищена, показаны начальные темы |
| Экран 390 × 844 | Карточки перестроены в колонку; горизонтальное переполнение отсутствует; форма занимает ширину экрана |
| Консоль браузера | Ошибки и предупреждения не обнаружены |
| Переключатель темы в шапке | Меняет светлую и тёмную палитры; переписка сохраняется при переключении |
| Обновление страницы после выбора темы | Выбранная тема сохраняется |
| Форма в тёмной теме | Поля, ошибки и кнопки используют соответствующую палитру |
| Переключатель на экране 390 px | Видим и помещается в мобильной шапке |
| Компактная страница после переноса в SupportPage | Внешняя прокрутка отсутствует на 1280×720, 1366×768, 1623×898 и 390×844; длинная переписка прокручивается внутри чата |

Прототип хранит данные только в памяти. Подключение реального портала, доставка обращений оператору и тестирование серверной интеграции не выполнялись: это вне текущей реализации.
