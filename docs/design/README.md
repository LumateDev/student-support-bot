# Макеты чат-бота поддержки учебного портала

Комплект для Александры Шмаковой и команды лабораторной работы 3. Макеты отражают текущую реализацию Vue и предназначены для дальнейшей работы над интерфейсом. Это статичные векторные экраны, а не отдельное приложение.

## Импорт в Figma

1. Распакуйте архив.
2. Для совпадения шрифта установите `fonts/GolosText-Variable.ttf`. Лицензия прилагается в `fonts/OFL.txt`.
3. Создайте пустой файл дизайна Figma и перетащите нужные SVG-файлы на холст.
4. Разгруппируйте нужный экран, чтобы работать с отдельными панелями, иконками и другими объектами.
5. Соберите повторяющиеся элементы в компоненты Figma; переходы прототипа, Auto Layout и варианты состояний настраиваются вручную.

SVG содержат нативные фигуры, текст и векторные иконки, без встроенных скриншотов. Обработка текста при импорте зависит от редактора: он может преобразовать текст в контуры. Исходные тексты экранов приложены в `copy.json`, шрифт — в `fonts/`. Поэтому надписи можно восстановить текстовыми слоями при необходимости. У SVG нет автоматической связи с исходным Vue-кодом.

## Структура и поведение

**Начальный экран.** Приветствие содержит примеры «Как авторизоваться?» и «Где конспекты?». Три карточки открывают ответы про вход, восстановление пароля и учебные материалы.

**Диалог.** Пользователь пишет вопрос или выбирает тему. Enter отправляет сообщение; Shift+Enter переносит строку. При пустом вводе отправка недоступна. Новый диалог очищает переписку.

**Неизвестный запрос.** Ответ объясняет границы справочника и предлагает открыть форму обращения. Не следует обещать ответ оператора в чате: реальная отправка ещё не реализована.

**Форма.** Имя, почта и описание обязательны. Пробелы не считаются содержимым. При ошибке показывается пояснение рядом с полем, фокус переходит к первому неверному полю. Ограничения: 60 символов для имени, 100 для почты, 500 для описания. После успешной проверки показываются демо-номер и подтверждение отсутствия отправки оператору.

**Темы.** Кнопка в шапке меняет светлую и графитовую темы. Палитры находятся в `tokens.json` и исходном `src/styles/themes.scss`. Выбор сохраняется между открытиями; переписка и обращения не сохраняются.

**Адаптация.** На desktop страница помещается по высоте, длинный диалог прокручивается внутри чата. При ширине до 700 px боковое меню превращается в компактную шапку, карточки FAQ располагаются в колонку. В мобильном SVG часть содержимого чата находится за границей области прокрутки — это предусмотренное поведение.

## Компоненты для дальнейшей работы

| Элемент | Состояния | Реализация |
| --- | --- | --- |
| Шапка и тема | Светлая, тёмная; кнопка включена/выключена | AppHeader.vue, ThemeToggle.vue |
| Боковая навигация | Обычная тема, выбранная тема, мобильная шапка | SupportSidebar.vue |
| Карточка FAQ | Обычная, наведение, фокус с клавиатуры | SupportChat.vue |
| Сообщение | Пользователь, помощник, неизвестный запрос | SupportChat.vue |
| Поле вопроса | Пустое, заполненное, фокус; отправка недоступна/доступна | SupportChat.vue |
| Форма обращения | Пустая, ошибки, заполненная, подтверждение | TicketDialog.vue |

Рекомендуемые исходные параметры: шрифт Golos Text; основной текст чата 14 px; заголовок страницы 30–36 px на desktop и 26–28 px на мобильном экране; скругление чата 16 px, карточек 10 px, полей 8 px. На компактных экранах отдельные размеры уменьшаются согласно реализации. Иконки — Lucide; лицензия приложена в `LUCIDE-LICENSE.txt`.

## Просмотр и исходные материалы

- `index.html` — галерея; откройте в браузере после распаковки, файлы SVG должны оставаться рядом.
- `tokens.json` — палитры и размеры экранов; это справочник, не файл импорта Figma Variables.
- `copy.json` — тексты макетов.
- `fonts/` — шрифт и его лицензия.

В репозитории дополнительно сохранены исходные геометрические данные `source/*.json` и скрипт `scripts/export-design.mjs`. Повторный экспорт: `node scripts/export-design.mjs` из корня проекта. Он обновляет SVG по сохранённым данным; после изменений живого интерфейса требуется новый захват состояний.
